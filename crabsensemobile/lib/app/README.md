# App Module

This directory contains application-level configuration, theming, routing, and initialization logic.

## Structure

- `app.dart` - Main application widget and configuration
- `theme.dart` - Material Design 3 theme configuration
- `router.dart` - GoRouter navigation configuration (to be added)
- `constants.dart` - App-level constants (to be added)

## Responsibilities

- Application initialization
- Theme and styling configuration
- Route definitions and navigation guards
- Global providers and dependency injection setup
