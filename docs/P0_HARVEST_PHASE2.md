# P0.3 phase 2 test checklist
- Mobile: open Ghi nhận lột / thu hoạch, tap assignment icon. Staff sees only own assigned tasks in authorized areas. Accept, enter per-crab measurements/outcome, defer with reason, optionally upload up to 3 images to the existing crab image endpoint before saving. Completion is online only and requires all lines processed. After error refresh task before retrying. Existing legacy direct harvest form sends request (not a completed harvest).
- Desktop: approved but unexecuted voucher → Yêu cầu điều chỉnh → select existing or additional available crabs, supply reason, submit. BE returns pending approval; another manager must approve. Old approval snapshots preserved; retained lines use current server DTO, not rounded UI weights.
- Real acceptance: two overlapping assignment/voucher submissions concurrently; only one reservation succeeds. Verify completion counts, released boxes, harvest history and images. Evidence in assignment path is uploaded to crab storage and attached by URL, not yet moved to a dedicated assignment folder. Frozen inventory and traceability verify separately with actual completed voucher. No automatic freezing or fake success.
