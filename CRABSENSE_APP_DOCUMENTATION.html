1. Tổng quan ứng dụng

🎯 Mục đích

CrabSense Mobile là ứng dụng enterprise IoT cho nhân viên vận hành trang trại nuôi cua. Giúp theo dõi sức khỏe cua, chất lượng nước, cảnh báo, thu hoạch và bán hàng ngay trên điện thoại — kể cả khi mất mạng.

👥 Đối tượng sử dụng

5 vai trò: Admin, Farm Manager, Field Operator, Sales, Viewer. Mỗi role có permission khác nhau: xem dữ liệu, ghi log, thu hoạch, bán hàng, cấu hình hệ thống.

📱 Nền tảng

Android (primary), iOS, Desktop, Web (với một số tính năng bị giới hạn — camera/biometric không hoạt động trên web). Hỗ trợ tiếng Anh và tiếng Việt.

🌐 Backend

REST API tại http://103.69.96.143:5080/api — .NET 8, PostgreSQL. Swagger: /swagger. Dùng JWT Bearer token, refresh token tự động.

2. Kiến trúc Clean Architecture

Mỗi feature được tổ chức theo 3 layer độc lập:

Presentation Layer — Screens, Widgets, BLoC/Cubit/Riverpod Providers
lib/features/*/presentation/screens/, lib/features/*/presentation/bloc/
Domain Layer — Use Cases, Entities, Repository Interfaces
lib/features/*/domain/usecases/, lib/features/*/domain/entities/
Data Layer — Repository Implementations, Data Sources (Remote/Local), Models
lib/features/*/data/datasources/, lib/features/*/data/repositories/

Dependency Injection: GetIt (sl) — lazy singletons cho services/repos/usecases, factories cho BLoC. Khởi tạo trong lib/core/di/injection.dart.

💧 Chất lượng nước

Water Quality Monitor

9. Bộ nhớ cục bộ & Offline

StoragePackageDùng choBảo mật
Drift SQLitedrift ^2.14.0Offline queue (SyncQueue), Box cache, Crab cache, Water readings, Alert history, Operation logs, Harvest, Sales, Video metadata, AI detections, InspectionsFile-level encryption

FlutterSecureStorageflutter_secure_storage ^9.0.0JWT access token, refresh token, expiry timestamps, biometric preference, FCM tokenKeychain (iOS) / Keystore (Android) — AES256

Offline Sync Architecture

Write path: User action → SyncQueue (SQLite) → UI phản hồi ngay → Background: BidirectionalSyncManager upload khi có mạng

Read path: Remote API → Drift SQLite cache → UI đọc từ cache → 30-day retention

Conflict resolution: Server-wins strategy + ConflictResolutionDialog cho manual conflicts

Retry: Exponential backoff 1s → 2s → 4s → 8s → 16s (max 5 lần)

Background sync: WorkManager (Android) / BGTaskScheduler (iOS) — periodic 15 phút
